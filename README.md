# Portfolio Nabil Falah

Portfolio personal untuk Nabil Falah, dibuat dengan React/Vinext dan Tailwind CSS.

## Menjalankan secara lokal

1. Pastikan Node.js versi 22 atau lebih baru tersedia.
2. Jalankan `npm install` bila folder `node_modules` belum tersedia.
3. Jalankan `npm run dev`.
4. Buka alamat lokal yang ditampilkan di terminal (biasanya `http://localhost:5173`).

## Screenshot project

Simpan screenshot di folder `public/images/` dengan nama berikut:

- `finance-bot-1.jpg` dan `finance-bot-2.jpg` — format portrait, ideal 9:16.
- `report-bot-1.jpg` dan `report-bot-2.jpg` — format portrait, ideal 9:16.
- `kabisat-1.jpg` dan `kabisat-2.jpg` — format landscape, ideal 16:9.

Jika gambar belum tersedia, halaman detail tetap menampilkan placeholder dengan ukuran yang sesuai. Data portfolio utama dapat diedit dari `app/page.tsx`, sedangkan isi detail project ada di `app/projects/[slug]/page.tsx`.
